# 개발(developer) 진행 메모

## 2026-07-31 — 로드맵 2단계: 고정 스킬 1개 발사

크래시 세션이 건너뛴 2단계를 순서대로 되돌아와 구현했다.
3단계(에디터) 코드는 이미 있지만 **일부러 쓰지 않았다.** 2단계가 3단계에 기대면
로드맵을 건너뛴 것과 같아진다. 수치는 `Player.gd` 에 직접 박아뒀고,
3단계에서 `SkillDB.get_slot("Q")` 로 바꿔 끼우면 된다.

### 새 파일
- `game/scripts/skill/Projectile.gd` — 투사체(Area3D).
  속도·사거리·판정 반경·데미지를 **스스로 정하지 않는다.** 쏘는 쪽이 `Balance.derive()`
  결과를 `configure()` 로 넘겨주고 그대로 쓴다. 노드(판정구·빛나는 구·광원)는 코드로 짓는다
  — 판정 반경이 밸런스 계산 결과라 매번 달라져서 `.tscn` 으로 고정할 수 없다.
  구현한 히트박스는 **둥긂(구체) 하나뿐**이다. 길쭉함/뾰족함/흩어짐은 3단계에서 붙인다.
- `game/scripts/Dummy.gd` — 허수아비. 맞으면 체력이 줄고 색이 튀고, 0이면 쓰러졌다가 2.5초 뒤 다시 선다.
  머리 위 `Label3D` 로 체력을 보여준다. **봇이 아니다** — 움직이지도 반격하지도 않는다.

### 고친 파일
- `game/scripts/Player.gd`
  - Q → `발동시간` 대기 → 발사 → `쿨타임`. 세 값 모두 Balance 가 정한 것을 그대로 쓴다.
  - **발동 중에 느려지게 하지 않았다.** 기획서가 "조준 중 감속"을 금지했고,
    피하는 수단이 이동·점프뿐이라 발동 중에도 그게 살아 있어야 한다.
  - `aim_direction()` / `cooldown_left()` 공개 — HUD 가 붙으면 쓸 창구.
  - 🐞 **버그 수정: 캐릭터가 뒤를 보고 달렸다.** `_face()` 가 몸의 **+Z** 를 진행 방향에
    맞추고 있었는데, Godot 의 앞은 -Z 고 `Player.tscn` 의 얼굴 메시도 -Z 쪽에 붙어 있었다.
    `atan2(dir.x, dir.z)` → `atan2(-dir.x, -dir.z)`. 발사 방향이 여기에 걸려서 같이 고쳤다.
- `game/scenes/Player.tscn` — 마법봉(막대 + 빛나는 끝 + `Muzzle`) 추가.
  기획서 12행 "마법봉으로 마법 쓰는 연출". 투사체는 이 끝에서 나간다.
- `game/scenes/Arena.tscn` — 허수아비 3개 (정면 9m / 좌측 / 우측).
- `game/project.godot` — 2행 주석에 `배그식` 이 아직 남아 있어 정정.
  감시자가 `Player.gd` 만 걷어내고 여기를 놓쳤다.

### 🐞 Godot 함정 (다시 밟지 말 것)
`Projectile` 에 `monitorable = false` 를 넣었더니 **허수아비·벽에 영영 안 맞았다.**
"이 투사체를 감지할 다른 Area 가 없으니 꺼도 되겠지" 하고 넣은 최적화였는데,
Godot 4.7 브로드페이즈가 monitorable 이 꺼진 Area 를 정적으로 취급해서
**StaticBody3D 와 아예 짝을 만들지 않는다.** 정적↔정적은 쌍이 안 생긴다.

증상이 고약하다 — 레이어/마스크/모양 전부 정상이고 `get_shape_owners()` 도 멀쩡한데
`get_overlapping_bodies()` 만 계속 0이다. 같은 자리에 플레인 Area3D 를 놓으면 잡힌다.
속성을 하나씩 바꿔가며 좁혀서 찾았다. `Projectile.gd` 에 주석으로 못박아뒀다.

### 검증 (Godot 4.7.1 헤드리스)
`--headless --import` 오류 0건. 그리고 임시 하네스로 실제 발사를 돌려 확인했다(검증 후 삭제):
- 표적 5m 앞에서 발사 → **10프레임 만에 명중, 체력 100 → 78** (데미지 22)
- 명중 20프레임 뒤 투사체 정리됨 (누수 없음)
- Q 입력 → 약 21프레임(발동시간 0.31초) 뒤 발사 — 입력부터 끝까지 이어짐
- 쿨타임 중 재입력 → 발사 안 됨 (차단 확인)

계산된 전투 수치(데미지 22 / 범위 18, 태그 둥긂):
쿨타임 4.94초 · 발동 0.31초 · 속도 25.1 m/s · 사거리 12.7m · 판정 반경 0.95m

### 기획 담당(game-designer)에게 넘길 것
**쿨타임 4.94초는 직접 쏴보면 길게 느껴질 수 있다.** 예산 공식(`cost = 22 + 18×0.6 = 32.8`)이
그대로 뱉은 값이라 코드에서 임의로 줄이지 않았다. 수치는 기획 담당 영역이다.
플레이 확인 뒤 `Balance.COOLDOWN_MIN/MAX` 를 조정할지 판단이 필요하다.
