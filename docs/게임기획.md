# 스킬 크래프트 배틀 (가제) — 게임 기획서

## 한 줄 컨셉
"내가 그린 스킬로 싸운다." 코어 루프 = 그림판에서 스킬 창작 → QWER 4칸에 형평성 있게 배치 → 5분 안에 맞히고 피하는 손맛.

## 코어 설계
- 5v5, 3인칭, PC. 이동 방향키 / 점프 스페이스바 / 스킬 QWER 4슬롯. 5분×3라운드.
- 스킬 제작(심장): 스킬 세팅 창(그림판)에서 모양 그리기 + 발사 형태 + 데미지(1~100) + 범위 설정.
- 형평성 원칙: 데미지 약할수록 쿨 짧게, 셀수록 쿨 길게. 범위 크고 세면 쿨 길고 발동 느림(피하기 쉬움). 범위 작고 세면 발동 빠름(피하기 어려움).
- 맵: 거대한 원룸 한 칸, 소형 인간들이 싸움. 캐릭터/속도는 멧챠 카멜레온풍.
- 자기장: 시간 지나면 배그처럼 안전구역 축소 → 강제 교전.
- 이펙트: 마법봉으로 마법 쓰는 연출. 회피: 이동 + 점프.

## 밸런스 공식 (제안)
공통 예산 100pt. 비용 = 데미지 + (범위×계수). 남은 예산으로 쿨/발동속도 자동 결정.

## 가장 중요한 미결정
그림 = 판정인가 겉모습인가. A안(겉모습만, 판정은 수치)=프로토타입 추천 / B안(그림 모양이 히트박스·궤적에 영향)=창의성↑ 난이도·악용↑, 나중 확장.

## 결정해야 할 빈칸
1. 그림=판정 vs 겉모습(1순위) 2. 스킬 종류 범위 3. 자원 시스템 4. 캐릭터 차별화 5. 승리 조건/리스폰 6. 부정 스킬·부적절 그림 대응 7. 온라인 매칭(나중).

## 엔진: Godot 4 (프로토타입, 2D 탑다운)

## 프로토타입 로드맵
1) 이동+점프 2) 고정 스킬 1개 발사 3) 스킬 에디터(수치판+예산공식) 4) QWER 4슬롯+봇 대전 5) 자기장 축소+5분 타이머 6) 재미 점검.
